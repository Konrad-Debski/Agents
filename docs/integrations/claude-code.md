# Claude Code

Claude Code otrzymuje symlink do `~/.claude/CLAUDE.md` i pojedyncze dowiązania skilli w `~/.claude/skills`. Adapter scala globalne `mcpServers` w `~/.claude.json`, zachowując pozostałe dane. Przy ustawionym `CLAUDE_CONFIG_DIR` adapter używa tego katalogu konfiguracji. Przy niestandardowych katalogach wybierz harness jawnie w `local.json` i zapewnij te same zmienne procesowi synchronizacji.
