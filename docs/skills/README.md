# Indeks skilli

Użyj tej mapy tylko wtedy, gdy harness nie pokazuje nazw i opisów skilli. Otwórz wyłącznie `SKILL.md` odpowiadający zadaniu. Wskazanie skilla nie upoważnia do publikacji ani wdrożenia.

| Zadanie | Skill |
| --- | --- |
| Aktualna dokumentacja bibliotek, frameworków, SDK, API, CLI i chmury | [context7-mcp](../../skills/context7-mcp/SKILL.md) |
| Pisanie i redakcja tekstów | [unslop](../../skills/unslop/SKILL.md) |
| Utworzenie lub aktualizacja PR oraz merge | [create-pr](../../skills/create-pr/SKILL.md) |
| Przeniesienie zmian motywów między spółkami Famicord | [famicord-sync](../../skills/famicord-sync/SKILL.md) |
| Brief implementacji sekcji WordPress/ACF z Figmy | [figma](../../skills/figma/SKILL.md) |
| Analiza lokalnej kopii WordPressa lub SQL po włamaniu | [wp-audit](../../skills/wp-audit/SKILL.md) |
| Aktualizacja WordPressa, wtyczek i ACF | [wp-update](../../skills/wp-update/SKILL.md) |
| Formatowanie wklejonych powiadomień o aktualizacjach | [wp-update-list](../../skills/wp-update-list/SKILL.md) |
| Doprecyzowanie wymagań i decyzji przed budową sekcji | [grill-me](../../skills/grill-me/SKILL.md), wywołuje [grilling](../../skills/grilling/SKILL.md) |
| Pisanie instrukcji i dokumentacji dla agentów | [writing-for-agents](../../skills/writing-for-agents/SKILL.md) |
| Diagnozowanie trudnego błędu lub regresji wydajności | [diagnosing-bugs](../../skills/diagnosing-bugs/SKILL.md) |

| Przegląd poprawności, bezpieczeństwa i zbędnego kodu w zmianach | [ponytail-review](../../skills/ponytail-review/SKILL.md) |

Opisy w metadanych służą wyborowi zadania. Pełne procedury, wymagania i opcjonalne referencje są w podlinkowanych skillach.

`grill-me` uruchamia użytkownik. W harnessie bez narzędzia `Skill` odczytaj wskazany `SKILL.md`, a potem `grilling/SKILL.md`. Samo dodanie tych skilli nie rozpoczyna wywiadu. Zachowujemy metadane wywoływania z upstream.

Dobór źródeł, zależności i sposób aktualizacji opisuje [upstream.md](upstream.md).
